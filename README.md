# Fuzzy Agentic Orchestration

A standalone GitHub Pages repository for the Medium-style article **Fuzzy Agentic Orchestration**.

## Publish on GitHub Pages

Upload the contents of this repository to a new GitHub repository. In GitHub, enable Pages from the repository root. `index.html` is self-contained and uses no external framework or build step.

## Medium

`medium_article.md` contains the clean article text in standard Markdown. The seven images are in `assets/` and are already inserted into the GitHub Pages version in the correct order.

## Repository contents

- `index.html` — GitHub Pages article
- `medium_article.md` — Medium-compatible article source
- `assets/` — seven figures

There are no hidden files or hidden folders.
